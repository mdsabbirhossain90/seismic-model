# Methods

This document describes the physics, numerical scheme and analysis used in this
repository. Symbols follow the source code.

## 1. Governing equations

2D P-SV wave propagation in an isotropic elastic medium, in velocity–stress form
(Virieux, 1986):

```
ρ ∂vx/∂t  = ∂σxx/∂x + ∂σxz/∂z
ρ ∂vz/∂t  = ∂σxz/∂x + ∂σzz/∂z
∂σxx/∂t   = (λ + 2μ) ∂vx/∂x + λ ∂vz/∂z
∂σzz/∂t   = λ ∂vx/∂x + (λ + 2μ) ∂vz/∂z
∂σxz/∂t   = μ (∂vx/∂z + ∂vz/∂x)
```

with λ = ρ(Vp² − 2Vs²) and μ = ρVs². The background is a Poisson solid:
Vp = 6000 m/s, Vs = Vp/√3 ≈ 3464 m/s, ρ = 2700 kg/m³.

## 2. Discretization

**Staggered grid.** Velocities and stresses live on interleaved grids, so every
spatial derivative is a centred difference. The 4th-order operator is

```
∂f/∂x ≈ [ C₁ (f(i+½) − f(i−½)) + C₂ (f(i+3/2) − f(i−3/2)) ] / Δx,
C₁ = 9/8,  C₂ = −1/24
```

and a 2nd-order operator is available for comparison (`--order 2`).

**Time stepping.** Leap-frog: stresses are updated from velocities, then velocities
from the new stresses (2nd order in time).

**Stability.** The CFL limit is

```
Δt_max = c · min(Δx, Δz) / (Vp_max · √2),   c = 6/7 (4th order), 1 (2nd order)
```

and the solver uses Δt = 0.6 Δt_max (4th order) for a safety margin.

**Numerical dispersion.** Before each run the solver computes the minimum points per
S wavelength, PPW = Vs_min / (f₀ Δx), and warns when PPW < 6 (4th order) or < 10
(2nd order). With Δx = 50 m, f₀ = 4.78 Hz and Vs clipped at ≥ 1800 m/s, PPW ≥ 7.5.

**Source.** An explosive source adds a Ricker wavelet
`s(t) = (1 − 2τ²) e^(−τ²)`, τ = π f₀ (t − t₀), t₀ = 1.5/f₀, equally to σxx and σzz.

## 3. Boundary conditions

Two strategies were implemented and compared.

**C-PML** (`pml_model/`, and `--pml N` in `nopml_50km/`). Convolutional PML with the
full (d, α, κ) stretching of Komatitsch & Martin (2007):

```
d(ξ) = d_max ξ^N,  κ(ξ) = 1 + (κ_max − 1) ξ^N,  α(ξ) = α_max (1 − ξ)
d_max = −(N + 1) Vp_max ln(R) / (2L),  N = 4, R = 1e-8, κ_max = 10, α_max = π f₀
```

The memory variables ψ are updated recursively with
`ψⁿ⁺¹ = b ψⁿ + a ∂f`, `b = exp(−(d/κ + α)Δt)`. Grid stretching (κ > 1) improves
absorption at grazing incidence, which matters here because source and receivers lie
on one horizontal line. The random perturbation is cosine-tapered to zero inside the
PML so the absorbing layer sees a laterally uniform medium and does not re-radiate.
Thicknesses of 20, 30 and 40 cells were compared (`pml_comparison/`).

**Padded domain** (`nopml_50km/`, used for the final results). The 40 × 40 km model
area is embedded in a 50 × 50 km grid (5 km pad on every side) with rigid walls.
No absorbing layer is used. Instead, every analysis window ends before the first
boundary-reflected P arrival, predicted with an image-source construction. This
removes any doubt about PML artefacts in heterogeneous media. Because the walls are
energy-conserving, total energy over the whole grid stays constant after the source
stops, which serves as a built-in correctness check.

## 4. Random media

A random fluctuation field ξ(x, z) is generated by spectral filtering:

1. draw white Gaussian noise η;
2. multiply its 2D FFT by √P(k), where P is the target power spectral density;
3. inverse FFT, then rescale so that std(ξ) = ε exactly.

Two autocorrelation models are supported (2D):

```
Exponential (von Kármán, κ = 0.5):  P(k) = 2π ε² a² / (1 + k²a²)^(3/2)
Gaussian:                           P(k) = π ε² a² exp(−k²a²/4)
```

Velocities are then `Vp = Vp₀ (1 + ξ)` and `Vs = Vs₀ (1 + ξ)` (fixed Vp/Vs ratio),
clipped to physical bounds. Density is kept constant.

**Anomaly mode.** A second, independent field (different seed) with RMS ε_anom
replaces the background inside a rectangular box (8 × 8 km centred at (22, 20) km),
so the anomaly differs in scattering strength but not in mean velocity.

**Scattering regime.** With k = 2π f₀ / Vp ≈ 5.0 × 10⁻³ m⁻¹, the correlation lengths
a = 0.3, 1 and 5 km give ka ≈ 1.5, 5 and 25, covering the range from strong
wide-angle scattering to forward scattering.

## 5. Wave-type separation and energy

P and S motion are separated with divergence and curl:

```
P = ∇·v = ∂vx/∂x + ∂vz/∂z,      S = (∇×v)_y = ∂vz/∂x − ∂vx/∂z
E_P = ½ ∫ (λ + 2μ) (∇·v)² dA,   E_S = ½ ∫ μ (∇×v)² dA
```

Total energy uses the kinetic energy plus the exact plane-strain strain energy
written in terms of stress:

```
W = ½ρ|v|² + (λ+2μ)/(8μ(λ+μ)) (σxx² + σzz²) − λ/(4μ(λ+μ)) σxx σzz + σxz²/(2μ)
```

Energies are reported both inside the 40 × 40 km region of interest and over the
whole grid.

## 6. Analysis metrics

Computed by `nopml_50km/thesis_figures.py`; exact definitions are in
[`data/metrics_definitions.txt`](data/metrics_definitions.txt).

| Metric | Definition |
|---|---|
| Predicted P time | t₀ + distance / Vp₀ |
| Direct peak | max \|v\| in t_P ± 0.4 s, also normalized by the homogeneous case |
| Traveltime shift | cross-correlation lag of vx against the homogeneous trace in t_P ± 0.5 s, refined to sub-sample precision by parabolic interpolation |
| Coda / direct energy | mean \|v\|² in [t_P + 0.5, t_P + 1.5] s divided by mean \|v\|² in t_P ± 0.4 s |
| Transverse coda fraction | share of vz² in the coda window (vx is radial on the receiver line) |
| E_S/E_P | ratio of S to P energy in the model area |
| Anomaly ratios | Case 3 divided by Case 2.1 at the same receiver: direct peak, late-coda energy, integrated (∇×v)² |

## 7. Monte Carlo radiative transfer

`pml_model/mc_solver.py` models energy transport as particles ("phonons") that move
in straight lines at speed V₀ and scatter isotropically after exponentially
distributed path lengths with mean free path ℓ. ℓ is estimated from (ε, a, f₀) with
the Born approximation for a Gaussian random medium. Particle counts in disks around
each receiver give energy envelopes E(t) that can be compared directly with smoothed
squared FD seismograms.

## 8. Verification

- `pml_model/smoke_test.py`: checks that the perturbation is zero inside the PML band,
  that no NaN/Inf or runtime warnings occur, that energy decays once the wave leaves
  the domain, and that the boundary field in a homogeneous control is negligible.
- With rigid walls, whole-domain energy is conserved after the source stops: over
  1–10 s it varies by only 0.63% (homogeneous), 0.23% (ε = 0.10) and 0.34% (anomaly case).
- `run_sets.py --quick` runs every case end to end in about one simulated second.
